# Daniil Privezentsev — Research & engineering

Полноценный статический личный сайт в выбранном графитовом дизайне Obsidian.

В сайт входят реальные контакты GitHub, LinkedIn, Telegram и email, CV, публичная версия research proposal, черновик статьи об агентной гранулярности, исследования, опыт и образование. У иллюстраций есть увеличение; навигация и анимации доступны с клавиатуры и учитывают системное уменьшение движения.

## Локальный просмотр

Откройте терминал в этой папке и выполните:

```text
python tools/build_site.py
python -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000/`. Для снимка без анимации добавьте `?view=still`.

## Публикация на GitHub Pages

Сайт: [daniil-novel.github.io](https://daniil-novel.github.io/).
Исходники: [daniil-novel/daniil-novel.github.io](https://github.com/daniil-novel/daniil-novel.github.io).

1. Создайте этот репозиторий в своём аккаунте GitHub либо сначала проверьте существующий одноимённый репозиторий.
2. Загрузите содержимое подготовленного пакета исходников. Файлы должны находиться в корне репозитория, без дополнительной внешней папки. Главная ветка — `main`.
3. В Settings → Pages выберите Source → GitHub Actions.
4. Запустите Publish research website во вкладке Actions. Адрес успешной публикации появится в результате задания.

Готовый workflow проверяет скрипты, собирает только публичные файлы, задаёт адрес для SEO/социальных превью и публикует сайт. Следующие изменения в `main` обновляют тот же адрес.

## Cloudflare Pages / Netlify

Для загрузки готовых файлов используйте содержимое `dist` или отдельный ZIP для хостинга. Папку `source` публиковать не нужно. Если известен итоговый адрес, перед загрузкой соберите так:

```text
python tools/build_site.py --base-url https://your-site.example/
```

HTTPS-адрес задаёт canonical URL, карту сайта и абсолютные адреса социального превью. Собственный домен можно подключить позднее; покупка домена не нужна для стандартного адреса платформы.

## Обновление

- Тексты и ссылки: `index.html`.
- Оформление: `assets/css/site.css`.
- Анимации: `assets/js/motion.js` и `assets/css/motion.css`.
- Меню и просмотр изображений: `assets/js/site.js`.
- PDF: `documents`. Имена файлов сохранены, чтобы адреса документов не менялись при замене.
- Фотография и иллюстрации: `assets/images`.

После обновления выполните `python tools/build_site.py` и `python tools/verify_site.py`.

Внешние ссылки намеренно ведут на публичные страницы. PolyMAS Studio доступна на GitHub; Swarm-INoT обозначен как исследование в разработке. Скриншот PolyMAS показывает настоящий интерфейс с демонстрационной конфигурацией, а не результат эксперимента. Research proposal — отдельная публичная английская адаптация авторского рабочего текста от 14 октября 2026 года.

Шрифты Space Grotesk и Instrument Sans поставляются локально с лицензиями OFL в `assets/fonts`. Работы, документы, фотографии и личные данные принадлежат их правообладателям; лицензия шрифтов на них не распространяется.
